# Mockups

The mockups are the visual source of truth for the watch UI.

## Files

- `presenta-screens (1).png`: the sheet "Presenta · Lámina de pantallas" (Wear OS, 454 × 454 px, round).
- `Presenta · Lámina de pantallas (1).pdf`: the same sheet as a PDF.

## Screens on the sheet

| # | Name | State |
|---|---|---|
| 01 | Inicio y conexión | Connected |
| 02 | Configuración | Before starting |
| 03 | Control principal | Normal state, key screen |
| 04 | Alerta de ritmo | Alert state, controls not blocked |
| 05 | Resumen final | Finished |
| 06 | Historial básico | With three records |
| 06b | Historial vacío | Empty variant |
| 07 | Sin conexión | Disconnected variant |

## Palette on the sheet

Night `#0C1424`, warm white `#F5EFE6`, cyan `#22D3EE` (action), amber `#FFB020` (alert).

See [../ui-direction.md](../ui-direction.md) for the full design direction and approved decisions.
